# Campus Resolve

Campus Resolve is a VB.NET-based student support and campus management application designed to simplify communication, issue reporting, and problem resolution within a college campus environment.

The project aims to provide students and administrators with a centralized platform where campus-related concerns can be reported, tracked, and resolved efficiently.

---

# Features

* Student Login and Authentication
* Admin Dashboard
* Complaint / Issue Registration
* Issue Tracking System
* Status Updates for Complaints
* Database Integration with MySQL
* User-Friendly Interface
* Secure Data Handling
* Campus Communication Support

# Installation Guide

## Step 1: Clone the Repository

```bash
git clone https://github.com/DAITA-SAATHWIKA/Campusresolve.git
```

## Step 2: Open the Project

* Open Visual Studio
* Click on "Open Project or Solution"
* Select `Campusresolve.sln`

---

# Database Setup

1. Install MySQL Server
2. Create a new database
3. Import the required tables
4. Update your MySQL connection string in the project

Example:

```vb
server=localhost;user id=root;password=YOUR_PASSWORD;database=campusresolve;
```
